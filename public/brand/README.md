# GitJuke mark

A quiet branch-shaped J for a personal pull request reading desk.

- `gitjuke-mark.png` is the transparent generated master. Keep its alpha channel.
- The sidebar uses its alpha as a CSS mask colored with `--theme-accent`, matching Graphite and Paper.
- `gitjuke-app-icon.png` adds a warm graphite rounded-square background for Applications and the Dock.
- Tauri's bundled icons are derived from the app icon with `bun run tauri icon public/brand/gitjuke-app-icon.png --output /tmp/gitjuke-icons`. Copy the desktop PNG, ICNS and ICO files into `src-tauri/icons/`.
- The existing monospace wordmark remains live text.

Created with the built-in image generation tool using the imagegen and frontend-design skills.

## Generation prompt

Use case: logo-brand
Asset type: GitJuke desktop application logo and small sidebar mark.
Primary request: Design one discreet, exquisitely minimal geometric symbol for a read-only GitHub pull request reader and personal activity monitor called GitJuke. A single strong monoline git branch subtly shaped like a lowercase j: two small circular terminal nodes connected by a clean upright stem and a rounded lower hook / returning branch. Aim for an elegant developer-tool maker's mark, quiet industrial precision, immediately legible at 24 pixels.
Style/medium: flat vector-like logo, crisp smooth edges, uniform substantial stroke, very simple silhouette, no tiny details.
Color palette: one solid muted warm brass #d6b98c only.
Scene/backdrop: genuinely transparent background.
Composition/framing: one centered standalone symbol, square canvas, symbol occupies approximately 70 percent of canvas height with balanced negative space.
Constraints: No text, no wordmark, no letters beside the symbol, no enclosing square or circle, no gradients, no shadows, no texture, no 3D, no mockup, no additional ornament, no music note. Exactly one final logo.

## Refinement prompt

Refine this exact GitJuke logo for production. Preserve the exact J-shaped branch silhouette, two hollow circular nodes, proportions, centered composition and transparent background. Change only rendering: make every stroke and edge perfectly smooth geometric vector-style curves; use ONE perfectly flat solid warm brass color #d6b98c with no metallic gradient or texture. Remove all speckles, stray pixels and rough edges, including inside the two holes. Holes and exterior must be entirely transparent. No other changes, no text, no enclosing shape. Square image.
